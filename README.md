# 💕 Site de Surpresa para Natália

Um site romanticamente decorado para o Dia dos Namorados, com senha de acesso, animações incríveis e a música "Ainda Bem" do Xande de Pilares.

## ✨ Características

- 🔐 **Tela de Senha Protegida** - Senha: `0703` (data do namoro)
- 💐 **Animações Bonitas** - Flores caindo, corações pulsando, efeitos de luz
- 🎵 **Música Romântica** - "Ainda Bem" - Xande de Pilares
- 💕 **Mensagem Personalizada** - Para Natália
- 📱 **Responsivo** - Funciona em celular, tablet e desktop
- ✨ **Design Elegante** - Rosa, branco e muitos efeitos

## 🚀 Como Usar

### Localmente
```bash
python3 -m http.server 8000
```
Depois acesse: `http://localhost:8000`

### Online (Vercel)
1. Vá para [vercel.com](https://vercel.com)
2. Clique em "New Project"
3. Selecione o repositório `site_natalia_surpresa`
4. Clique em "Deploy"
5. Pronto! Seu site estará online

## 📝 Instruções de Acesso

1. Abra o site
2. Veja a tela de senha bonita
3. Digite: `0703`
4. Clique em "DESBLOQUEAR ❤️"
5. Veja a mensagem linda
6. Clique em 🎵 para tocar a música
